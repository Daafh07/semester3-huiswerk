# Acme to Next.js

Workshop 1: rebuilding the static Acme website as a Next.js app (App Router, TypeScript, Tailwind CSS). It has a home page, a products page and a contact page, built from reusable components (`Header`, `Footer`, `ProductCard`).

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
