# Week 2, part A: routing and dynamic pages

Extends the Acme shop with dynamic routes. Each product has its own page (`/products/[id]`), and the app uses the special Next.js files `loading.tsx`, `error.tsx` and `not-found.tsx` for loading states, errors and missing pages.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
